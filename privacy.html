Privacy Policy

Echoes of Gita Studio · Last updated 20 October 2026

Who uses this app

Echoes of Gita Studio is a personal tool used only by its owner to upload videos to the owner's own YouTube channel. It has no other users and no sign-up.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

The app requests only the youtube.upload permission. It uses it to upload finished videos, with their title, description and tags, to the owner's channel. It does not read, store or share viewer data, comments, subscriber lists, or any other Google account data.

How credentials are stored

The YouTube authorization token is stored as an encrypted secret in the owner's GitHub repository and is used only by the app's automated upload job. It is never shared with third parties.

Revoking access

Access can be revoked at any time from the Google security settings page.

Contact

Questions about this policy can be raised on the project's GitHub page.
